How this was counted

A start is a player's first — regular-season games played, in date order. The comparison pool is every player-season in NHL history that reached that many games: — starts across — seasons, built from — regular-season skater game lines pulled from the NHL's stats API.

Raw points are as the league recorded them. Scoring has swung widely, from about 7.4 goals a game in the late 1980s to about 5.3 in the late 1990s, so the era-adjusted count scales each goal and each assist by how common they were that season compared with 2023-24 through 2025-26. Early seasons credited far fewer assists per goal, which no scaling repairs, so the adjusted ranking starts in —, the first season of the unbroken run in which assists per goal sit within 15% of today's rate.
